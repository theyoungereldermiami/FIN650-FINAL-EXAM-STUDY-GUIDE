How this deck was built

The flashcards reproduce the provided professor practice bank for Chapters 8, 9, 18, and 24, then add study tags (difficulty, math Y/N, topic, and formula type). Table inputs that were embedded as images in the source PDF are repeated in text so each question is self-contained.

Formula scope

The formula library follows Lecture 4 (asset pricing/CAPM), Lecture 5 (performance evaluation), Lecture 6 (income hedging), and Lecture 7 (equity valuation). A small “Prerequisite” section includes earlier formulas only where the final material directly reuses them.

Notation note

Chapter 18 practice questions use k for the required/discount rate while Lecture 7 uses r. The source explicitly treats these as alternative notation; the formula library mainly uses r.
