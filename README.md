# FIN650 Final Study Studio

A self-contained final-exam study app built from the provided FIN650 course sources.

## Contents
- `index.html` — browser app; open directly in Chrome/Edge/Safari/Firefox.
- `data/practice_questions.csv` — 71 professor-provided practice questions, tagged by chapter, difficulty, math Y/N, topic, and formula type.
- `data/formulas.csv` — 61 formula/reference rows, including final-exam formulas and prerequisite formulas from the prior exam that are directly reused.
- JSON copies of both datasets for reuse.

## Scope used
Final: Chapters 8, 9, 18, 24 from Lectures 4, 5, 7, plus Lecture 6 income hedging, per your requested scope. The formula library also includes a small prerequisite section from Chapters 5–7 where those formulas are reused by final material.

## Run
Double-click `index.html`. No R, Python, package installation, or internet connection is required.

Progress is stored locally in your browser. If browser storage is unavailable or corrupt, the app automatically falls back to a clean session rather than hanging on “Loading saved progress…”.
